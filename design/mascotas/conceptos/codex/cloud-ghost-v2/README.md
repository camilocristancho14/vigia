# Cloud Ghost v2

A fluffy cloud ghost in Codex colors. It has a bumpy, many-lobed cloud top like the Codex mark, a scalloped ghost hem, a vertical lavender to blue-violet to indigo gradient, and a darker indigo outline. While working its eyes turn into the white `>_` prompt from the Codex logo, the cursor blinks, and small lavender/indigo data bits rise along its sides. When sleeping it sags softly, breathes and lets out Zz.
